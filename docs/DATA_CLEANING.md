# บันทึกการทำความสะอาดข้อมูล (Data Cleaning Log)

ข้อมูลดิบทั้ง 5 ชุด **ไม่ถูกแก้ไขหรือเขียนทับ** ทุกการแก้ไขทำในโค้ด (`data_processing/transform.py`) แล้วบันทึกผลที่ `data/processed/`
ตัวเลขก่อน/หลังของแต่ละขั้นถูกสร้างทุกครั้งที่รัน pipeline และบันทึกไว้ที่ `data/processed/cleaning_log.csv` (แสดงในแท็บ "คุณภาพข้อมูล" ด้วย)

รันซ้ำ: `python -m data_processing.pipeline`

| ปัญหา | จำนวน | วิธีจัดการ | เหตุผล |

| สัปดาห์ที่ไม่มีการแถลงในช่วงที่แถลง | 3 สัปดาห์ (14–20 มิ.ย., 26 ก.ค.–1 ส.ค., 25–31 ต.ค.) | คงเป็นค่าว่าง **ไม่เติม 0** เส้นกราฟขาดช่วง | 0 คดีหมายถึงไม่มีคดี ซึ่งไม่จริง |

## สิ่งที่ตั้งใจ **ไม่** ทำ

- ไม่เติมค่า (imputation) ให้สัปดาห์/ปี/ประเทศที่ไม่มีข้อมูล
- ไม่ลบแถวผิดปกติทิ้งจากไฟล์ แค่ไม่นับในสถิติและแสดงให้เห็นในตารางคุณภาพข้อมูล
- ไม่แปลงสกุลเงิน ไม่ปรับเงินเฟ้อ
- ไม่ตัดสินความถูกต้องของข้อมูลต้นทาง (เช่น ว่า 79,311 คดีผิดแน่นอน) บอกเพียงว่าน่าสงสัยเพราะเหตุใด
