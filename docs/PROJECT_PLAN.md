# แผนงานโครงการ: ภัยข่าวปลอมและการหลอกลวงออนไลน์ (Dashboard)

สถานะ: ✅ เสร็จแล้ว · 🔄 กำลังทำ · ⬜ ยังไม่ทำ (อัปเดต 2 พ.ย. 2026)

## 1. เป้าหมาย

สร้างแดชบอร์ด Python (Streamlit + Pandas + Plotly) แบบเดียวกับ *Thailand Unemployment Intelligence Dashboard*
ที่ตอบคำถามเรื่องข่าวปลอมและภัยหลอกลวงออนไลน์ในไทย โดยใช้ข้อมูลหลายชุดเทียบกับบริบทโลก พร้อมขึ้น GitHub

**เงื่อนไข**
- ใช้ข้อมูลอย่างน้อย 3 ชุด (โครงการนี้ใช้ 5 ชุด)
- Python เป็น backend: ทำความสะอาด/คำนวณด้วย pandas ใน `data_processing/` และ `analytics/` ส่วนแดชบอร์ดอ่านเฉพาะตารางที่ประมวลผลแล้ว
- ไม่สร้างหรือประมาณข้อมูลเอง ข้อมูลที่ขาดแสดงเป็นช่องว่างพร้อมคำอธิบาย
- เสร็จก่อนเที่ยง 2 พ.ย. 2026

## 2. สถาปัตยกรรม

```
ไฟล์ดิบ (data/raw หรือโฟลเดอร์ 01–04)
   │  data_processing/loaders.py      อ่านไฟล์
   ▼
data_processing/transform.py          ทำความสะอาด + สร้างตารางสรุป (ฟังก์ชันล้วน ทดสอบได้)
data_processing/validation.py         ตรวจคุณภาพ 16 รายการ
data_processing/pipeline.py           รวมทุกขั้น → data/processed/*.csv + meta.json
   ▼
data/processed/                       ตารางที่คลีนแล้ว (commit ขึ้น GitHub ได้ ขนาดรวม ~8 MB)
   │  data_processing/store.py        โหลดตาราง
   ▼
analytics/metrics.py                  KPI, การเปลี่ยนแปลง, สหสัมพันธ์, อันดับ
   ▼
dashboard/ (theme, charts, components, pages) + app.py   7 แท็บ
```

ตัดสินใจสำคัญ
| เรื่อง | ตัดสินใจ | เหตุผล |
|---|---|---|
| ไฟล์ดิบขึ้น GitHub? | ไม่ขึ้น (อยู่ใน .gitignore) | `afnc_items.csv` 68 MB, AIID/AFNC/ACSC ไม่ระบุสัญญาอนุญาต |
| ตารางที่ประมวลผลแล้ว | ขึ้นได้ | clone แล้วรันได้ทันที ไม่ต้องมีไฟล์ดิบ |
| เนื้อหาข่าวเต็ม (`content`) | ไม่นำเข้า | ไม่จำเป็นต่อคำถามที่ตั้ง ลดขนาดและความเสี่ยงลิขสิทธิ์ |
| ไลบรารีกราฟ | Plotly | ช่องว่างในเส้น, แถบไฮไลต์, แผนที่ choropleth, ฟอนต์ไทย |
