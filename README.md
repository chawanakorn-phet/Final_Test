# Digital Freedom & Disinformation Intelligence Dashboard
**แดชบอร์ดวิเคราะห์เสรีภาพทางอินเทอร์เน็ต ข่าวปลอม และความเสียหายจากมิจฉาชีพ**

วิเคราะห์ความสัมพันธ์ระหว่างเสรีภาพทางอินเทอร์เน็ต สถานการณ์ข่าวปลอม และความเสียหายจากมิจฉาชีพ เปรียบเทียบประเทศไทยกับต่างประเทศ ด้วยข้อมูลสาธารณะ **5 ชุด**
ที่แนบมาเท่านั้น (AFNC, ACSC, EUvsDisinfo, AI Incident Database, Freedom on the Net)

> **หลักการ:** ไม่สร้างหรือประมาณตัวเลขเอง · สัปดาห์/ปีที่ไม่มีข้อมูลแสดงเป็น **ช่องว่าง ไม่ใช่ 0** · เมื่อข้อมูลไม่พอหรือเชื่อมกันไม่ได้ ระบบแสดง
> "ไม่มีข้อมูลเพียงพอสำหรับการวิเคราะห์นี้" พร้อมเหตุผล แทนการคำนวณที่ผิดหลักสถิติ · สหสัมพันธ์ไม่ใช่เหตุและผล

## สถาปัตยกรรม (หลายภาษาทำงานร่วมกัน)

```
ไฟล์ข้อมูลดิบ ──► Python (pandas)         data_processing/   อ่าน ทำความสะอาด ตรวจคุณภาพ → data/processed/*.csv
                  Python (scipy, statsmodels, pandas)
                                          analytics/         สถิติ สหสัมพันธ์ จุดเปลี่ยน ความผิดปกติ พยากรณ์
                                          pipeline/          รวมทุกอย่างเป็น docs/data.js (1.9 MB)
                                              │
                  HTML + CSS + JavaScript ◄───┘
                                          docs/              index.html · style.css · logic.js · app.js · tabs_*.js · boot.js
                                          Apache ECharts     กราฟ (โหลดจาก CDN)  → เปิดบน GitHub Pages ได้
```

| ภาษา | หน้าที่ |
|---|---|
| **Python** | ประมวลผลข้อมูลดิบ ตรวจคุณภาพ ทดสอบสถิติ พยากรณ์ 5 แบบจำลอง ตรวจความผิดปกติ สร้างรายงานสรุป และสร้าง `docs/data.js` |
| **JavaScript** | ตัวกรองที่เชื่อมทุกแท็บ การรวมข้อมูลตามเดือน/ไตรมาส/ปี สหสัมพันธ์ที่คำนวณใหม่ตามตัวกรอง (ทดสอบเทียบกับ scipy) กราฟ ตาราง ส่งออก CSV |
| **HTML / CSS** | หน้าปก โครงหน้า แถบนำทาง ตัวกรองด้านข้าง (กลายเป็นลิ้นชักบนมือถือ) ธีมขาว-แดง |

## เริ่มใช้งาน

```powershell
pip install -r requirements.txt
python -m pipeline.build_data                    # สร้าง docs/data.js จากตารางใน data/processed/
python -m http.server 8765 --directory docs      # เปิด http://localhost:8765
```

เปิด `http://localhost:8765` แล้วกด **Open Dashboard** (หรือเปิด `…/index.html#app` เพื่อข้ามหน้าปก) · ต้องมีอินเทอร์เน็ตเพื่อโหลด ECharts และฟอนต์

ถ้าต้องการประมวลผลข้อมูลดิบใหม่ (วางโฟลเดอร์ `01_…`–`04_…` ไว้ใน `data/raw/` หรือกำหนด `FT_RAW_DIR`):

```powershell
python -m data_processing.pipeline               # ข้อมูลดิบ → data/processed/ (ราว 1 นาที)
python -m pipeline.build_data                    # → docs/data.js
```

**เผยแพร่บน GitHub Pages:** Settings → Pages → Branch `main`, Folder `/docs` (ไฟล์ `docs/data.js` ถูก commit ไว้แล้ว เปิดได้ทันทีโดยไม่ต้องมีข้อมูลดิบ)

## ตัวกรอง (แถบด้านซ้าย ใช้ร่วมกันทุกแท็บ)

ช่วงวันที่ · ปี · ไตรมาส · เดือน · ประเทศไทย/ต่างประเทศ · กลุ่มประเทศและประเทศ · ประเภทข่าว · สถานะข่าว (ปลอม/บิดเบือน/จริง/อื่น ๆ) · หมวดหมู่ความเสียหาย · แหล่งข้อมูล
พร้อมแถบ "ตัวกรองที่ใช้อยู่" และปุ่ม **Reset Filters**

| ตัวกรอง | ใช้กับ | เมื่อใช้ไม่ได้ |
|---|---|---|
| ช่วงวันที่ / ปี / ไตรมาส / เดือน | AFNC, ACSC, EUvsDisinfo, AIID (Freedom on the Net ใช้เฉพาะส่วนปี) | แจ้งว่าเดือน/ไตรมาสไม่ใช้กับข้อมูลรายปี |
| ประเทศไทย / ต่างประเทศ | ไทย: AFNC, ACSC, คะแนนไทย · ต่างประเทศ: EUvsDisinfo, ประเทศอื่น | ข้อมูลที่อยู่นอกขอบเขตแสดง "เป็นข้อมูลของประเทศไทยเท่านั้น" แทนตัวเลข |
| กลุ่มประเทศ / ประเทศ | Freedom on the Net (ไทยแสดงเสมอเป็นจุดอ้างอิง) | — |
| ประเภทข่าว / สถานะข่าว | AFNC เท่านั้น | EU ใช้การจัดหมวดคนละระบบ จึงไม่ถูกกรอง |
| หมวดหมู่ความเสียหาย | ACSC — เลือกสัปดาห์ที่ประเภทเสียหายสูงสุดตรงกับที่เลือก | — |
| แหล่งข้อมูล | เปิด/ปิดแต่ละชุด | ชุดที่ปิดแสดงเหตุผล |

**ที่ไม่เปลี่ยนตามตัวกรองโดยตั้งใจ:** ข้อค้นพบเชิงสถิติ การแยกส่วนความเสียหาย จุดเปลี่ยน การทดสอบ lag และ **ค่าพยากรณ์** — คำนวณจากข้อมูลทั้งช่วงด้วย Python
เพราะการรันซ้ำบนช่วงที่ผู้ชมลากเองให้ตัวเลขที่ดูแม่นแต่เทียบกันไม่ได้ (บอกไว้ในหน้าด้วย) ส่วน **ตารางสหสัมพันธ์ในแท็บ 4 คำนวณใหม่ตามตัวกรอง**

## สถิติและการพยากรณ์

| เรื่อง | วิธี | เงื่อนไขที่ระบบ "ปฏิเสธ" |
|---|---|---|
| สหสัมพันธ์ | Spearman (หลัก) / Pearson, two-sided p-value, รายงาน n | มีคู่ข้อมูลน้อยกว่า 10 คู่ หรือตัวแปรคงที่ → "ไม่มีข้อมูลเพียงพอสำหรับการวิเคราะห์นี้" |
| เสรีภาพ ↔ ข่าวปลอม (ไทย รายปี) | Spearman | ซ้อนกันเพียง 5 ปี (2020–2024) → ไม่คำนวณ |
| เสรีภาพ ↔ ความเสียหาย | — | ACSC เริ่ม พ.ย. 2025 แต่ Freedom on the Net สิ้นสุดปีข้อมูล 2024 → ไม่มีช่วงที่ซ้อนกัน |
| พยากรณ์ | Naive, Moving average, Exponential smoothing, Holt (damped), ARIMA(1,1,1) เปรียบเทียบด้วย rolling-origin back-test เลือก RMSE ต่ำสุด รายงาน MAE/RMSE | ข้อมูลน้อยกว่าเกณฑ์ (36 จุดรายเดือน / 40 จุดรายสัปดาห์) |
| ช่วงความไม่แน่นอน | ± 1.96 × RMSE ของ back-test (ประมาณ ไม่ใช่ช่วงความเชื่อมั่นเชิงทฤษฎี) | — |

ค่าพยากรณ์แสดงเป็นเส้นประสีน้ำเงินพร้อมแถบ แยกจากข้อมูลจริง (เส้นทึบสีแดง) ชัดเจน · ความเสียหายรายสัปดาห์มีข้อมูลสั้นและมีจุดเปลี่ยน เม.ย. 2026 จึงใช้พยากรณ์ได้เพียง 4 สัปดาห์และมีคำเตือนกำกับ
· จำนวนคำตัดสินข่าวปลอมเป็นโควตาของศูนย์ฯ (~49 เรื่อง/สัปดาห์) การพยากรณ์จึงสะท้อนการทำงานของศูนย์ฯ ไม่ใช่ปริมาณข่าวปลอมในสังคม

## คำถามวิเคราะห์ (3 ข้อ)

แต่ละข้อมีหน้าของตัวเองในเมนู (Q1–Q3) ข้อย่อยที่ **ข้อมูลตอบไม่ได้หรือตอบได้จำกัด** ระบุไว้ท้ายแต่ละข้อ

### Q1 รูปแบบ เนื้อหา และประเภทของข้อมูลบิดเบือนต่างกันอย่างไรระหว่างระดับนานาชาติกับไทย และอะไรเปลี่ยนไปตามเวลา
*ใช้ EUvsDisinfo เทียบกับ AFNC*

| ข้อย่อย | คำตอบเบื้องต้น (คำนวณจากไฟล์) |
|---|---|
| ประเด็นระดับนานาชาติ | สงครามยูเครน (1,381 เรื่อง), ต่อต้านรัสเซีย, ทฤษฎีสมคบคิด, ตะวันตก, NATO |
| ข่าวปลอมไทยพบมากหมวดใด | นโยบายรัฐ (39% ของข่าวเท็จปี 2025) สุขภาพ การเงิน-หุ้น ภัยพิบัติ |
| ประเภทที่เปลี่ยนมากที่สุด | สุขภาพ 61% (2020) → 16% (2026) · การเงินพุ่ง 2022–2025 · ข่าวเท็จเรื่องแอบอ้าง/หลอกลวง 1.2% → 36.9% (2020→2025) |
| สัดส่วนข่าวจริง/ปลอม/บิดเบือน | ไทย (2020–): ปลอม 66% · บิดเบือน 10% · จริง 24% · สัดส่วนเท็จรวม 82.9% → 71.2% (z = −7.4) |
| ประเด็นที่ซ้ำและเพิ่มขึ้น | ไทย (2022→2025): เพจปลอม +12.7 จุด, ไทย-กัมพูชา +10.8 · EU (2019→2022): สงครามยูเครน 8% → 54% · โควิดเป็นประเด็นใหญ่ทั้งสองฝั่งปี 2020 (ไทย 30%, EU 22%) แล้วลดเกือบหมดหลังปี 2022 |

**ตอบไม่ได้/จำกัด:** (1) ไม่เทียบ "เนื้อหา" รายบทความของ EU เพราะไฟล์มีแค่ลิงก์ ไม่มีข้อความ (2) เทียบสัดส่วนข่าวจริง/ปลอม/บิดเบือนข้ามฝั่งไม่ได้ เพราะ EU ไม่มีป้ายเหล่านี้ (มีแค่ disinformation/trustworthy) (3) EU เก็บเฉพาะฝั่งสนับสนุนรัสเซียและสิ้นสุด ส.ค. 2023 (4) หมวดของสองฝั่งเป็นคนละระบบ เทียบเชิงเนื้อหา ไม่ใช่จับคู่รายหมวด (5) หมวดของ AFNC เปลี่ยนนิยามปี 2026

### Q2 ข่าวปลอมและภัยหลอกลวงออนไลน์ในไทยมีแนวโน้มและความเสียหายเปลี่ยนไปอย่างไร และตรวจจับช่วงผิดปกติได้หรือไม่
*ใช้ AFNC และ ACSC (ตารางรายสัปดาห์)*

| ข้อย่อย | คำตอบเบื้องต้น |
|---|---|
| แนวโน้ม | คดีเฉลี่ย 6,800–7,450/สัปดาห์ (พ.ย.–มี.ค.) → 5,350–5,650 (พ.ค.–ก.ค.) → 6,000+ (ต.ค.) · จุดเปลี่ยนช่วง เม.ย. 2026: คดี −20%, บาท/คดี −34% |
| ช่วงผิดปกติ | คดี 16–22 ส.ค. 2026 (79,311 คดี, robust z ≈ 61) ถูกตัดออก · ตรวจเพิ่มด้วยค่ามัธยฐานของสัปดาห์รอบข้าง: บาท/คดี 1 สัปดาห์, ข่าวเท็จ 3, สัดส่วนข่าวเท็จ 2 |
| ประเภทที่เสียหายมากสุด | "หลอกลงทุน" เป็นอันดับ 1 ด้านความเสียหาย 18 จาก 44 สัปดาห์ที่มีข้อมูล (ด้านจำนวนคดีคือ "หลอกซื้อขายสินค้า/บริการ") |
| คดีเพิ่มสัมพันธ์กับความเสียหายไหม | ใช่ r = +0.84 และคดี +1% ↔ ความเสียหาย +2.5% |
| คดีลดแต่บาท/คดีเพิ่ม | พบ 1 จาก 10 บล็อก (4 สัปดาห์): 2 ส.ค.–27 ก.ย. 2026 คดี −9%, บาท/คดี +11% |

## ข้อจำกัดที่ต้องรู้

- **ตัวเลขคดีมาจากข่าวแถลงรายสัปดาห์ ไม่ใช่ข้อมูลเปิดของตำรวจ** และเป็นเฉพาะคดีที่มีผู้แจ้งความ
- ข้อมูลคดีมีเพียง 47 สัปดาห์ใช้ได้ จึงไม่ใช่แนวโน้มระยะยาว
- จำนวนคำตัดสิน AFNC คือสิ่งที่ศูนย์ฯ เลือกตรวจ ไม่ใช่ปริมาณข่าวปลอมจริง
- นิยาม deepfake ในโครงการนี้ (526 เหตุการณ์) กว้างกว่าการนับเฉพาะคอลัมน์ระบบของ AIID (คู่มือรายงาน 439)
- AIID/AFNC/ACSC ไม่ระบุสัญญาอนุญาต: ให้อ้างอิงแหล่งที่มา และตรวจสิทธิ์ก่อนเผยแพร่ต่อสาธารณะ

1. รูปแบบ เนื้อหา และประเภทของข้อมูลบิดเบือนแตกต่างกันอย่างไรระหว่างแหล่งข้อมูลระดับนานาชาติกับประเทศไทย และมีรูปแบบใดที่เปลี่ยนแปลงอย่างมีนัยสำคัญตามช่วงเวลา?
สิ่งที่ต้องการค้นหาคำตอบ

ศึกษาลักษณะของข้อมูลบิดเบือนในระดับนานาชาติเปรียบเทียบกับข้อมูลข่าวปลอมที่ศูนย์ต่อต้านข่าวปลอมประเทศไทยตรวจสอบ โดยเน้นการค้นหารูปแบบของเนื้อหา ประเภทข่าว และการเปลี่ยนแปลงของประเด็นที่พบ

สามารถนำไปตอบอะไรได้บ้าง
- ประเด็นข้อมูลบิดเบือนในระดับนานาชาติมีลักษณะอย่างไร
- ข่าวปลอมในประเทศไทยพบมากในหมวดหมู่ใด เช่น สุขภาพ การเงิน นโยบาย หรือภัยพิบัติ
- ประเภทข่าวปลอมใดมีการเปลี่ยนแปลงมากที่สุดตามช่วงเวลา
- ข่าวจริง ข่าวปลอม และข่าวบิดเบือนมีสัดส่วนแตกต่างกันอย่างไร
- มีหมวดหมู่หรือประเด็นใดที่ปรากฏซ้ำและมีแนวโน้มเพิ่มขึ้นหรือไม่

2. ภัยคุกคามด้านข้อมูลข่าวสารและอาชญากรรมหลอกลวงออนไลน์มีแนวโน้มและระดับความเสียหายเปลี่ยนแปลงอย่างไร และสามารถตรวจจับช่วงเวลาที่มีความเสี่ยงหรือความผิดปกติได้หรือไม่?
สิ่งที่ต้องการค้นหาคำตอบ

ศึกษาความเคลื่อนไหวของข่าวปลอมและภัยหลอกลวงออนไลน์ในประเทศไทย โดยพิจารณาทั้งจำนวนเหตุการณ์ มูลค่าความเสียหาย ประเภทของภัย และความผิดปกติของข้อมูลในแต่ละช่วงเวลา

สามารถนำไปตอบอะไรได้บ้าง
- ข่าวปลอมและภัยหลอกลวงออนไลน์มีแนวโน้มเปลี่ยนแปลงไปในทิศทางใด
- ช่วงเวลาใดมีจำนวนข่าวปลอมหรือจำนวนคดีหลอกลวงสูงผิดปกติ
- ประเภทการหลอกลวงใดสร้างความเสียหายทางการเงินมากที่สุด
- จำนวนคดีที่เพิ่มขึ้นสัมพันธ์กับมูลค่าความเสียหายหรือไม่

- แนวโน้มข่าวปลอมกับความเสียหายจากการหลอกลวงมีความสัมพันธ์กันในช่วงเวลาเดียวกันหรือเหลื่อมเวลากันหรือไม่
